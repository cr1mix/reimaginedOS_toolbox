## What is it?

The ToolBox is the companion app of [ReimaginedOS](https://github.com/cr1mix/ReimaginedOS). After the playbook runs, the ToolBox manages the same tweaks from a window: flip a toggle, it applies; flip it back, it reverts.

<div align="center">

| System | Performance | Information |
| :---: | :---: | :---: |
| Services · Wi-Fi · Bluetooth · Power | CPU / GPU settings and controls | Windows · CPU · RAM · GPU · Power plan |

</div>

---

## Features

- **Mirrors the playbook** — The same toggles as PostInstall scripts, with live on/off detection.
- **Presets** — Gaming Max and Balanced Daily one-click sets, plus save/load of your own profiles.
- **Power tools** — System file repair, component store cleanup, network and gaming service repair.
- **App setup** — Clean installs of common apps and browsers, driver install helpers.
- **Reads apply logs** — Shows playbook version, Defender state and what actually changed on your system.

---

## Requirements

- Windows 10 / 11 x64
- Administrator rights (it will ask on launch)
- Nothing else — self-contained, no runtime to install
